# Portfolio

Personal site for Jaunte Kelvin Garcia: the WIOS platform (Learn, Analytics, Console and its AI dev crew), capabilities, public GitHub projects and a timeline.

## Run

```bash
pnpm install
pnpm dev            # http://localhost:5173
pnpm build          # type-check and build to dist/
```

## Content

- `src/data/profile.ts`: the hand-written content (intro, WIOS products, capabilities, journey, contact links). The WIOS repos are private, so describe what they do, never their code or secrets.
- `src/data/github.json`: public profile and repos, generated by `pnpm sync:github` (set `GITHUB_TOKEN` to avoid the anonymous rate limit). Re-run it when you publish a new repo.

## Deploy

`.github/workflows/pages.yml` builds and deploys to GitHub Pages on every push to `main`. Enable Pages in the repo settings with **Source: GitHub Actions**. Name the repo `JaunteGarciaZa.github.io` to serve it from the root domain.
